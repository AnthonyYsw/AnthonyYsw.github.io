## Name

The file must be in markdown format, named "YYYY-MM-DD-N.md", where N represents the Nth post of the day.

Example: "2004-06-27-1.md"

## Add an image

Currently no one has write access except myself, so this posting is just for me.

The files are stored on an AliCloud server as the Github Page only includes 1GB of storage. Citing images should not only follow markdown writing principles, but also link to them correctly. The link to the image can be found in the AliCloud OSS console, so link the image:

```liqud
![Name of the Image](https://somelink.png)
```

Web pages sometimes need to compress images to ensure fast loading, but I have a high pursuit of colour, so only pixel compression is allowed not colour depth. Link a compressed image:

```liqud
![Name of the Image](https://somelink.png?x-oss-process=image/resize,w_200/quality,q_85)
```

In addition to this, if you want to display beautiful images, you can choose to use pre-written presentations:

```liquid
    {% include photo.html
        small_src="https://somelink.png?x-oss-process=image/resize,p_60/quality,q_85"
        large_src="https://somelink.png"
        alt="name"
        aperture="f/8"
        shutter="1/500"
        iso="200"
    %}
```

For a gallery view:

```liquid
<div class="gallery">
    <!-- list photo here -->
</div>
```
